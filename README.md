# Bulbam

**Бульбам** — web-first мессенджер. Сначала надёжный мессенджер, потом уже очень странный белорусский мессенджер.

## Что строим

Первая версия работает в браузере и разворачивается одним Cloudflare Worker. Worker обслуживает API по `/api/*` и статический веб-клиент.

Главные правила архитектуры:

- сервер — источник истины для аккаунтов и сообщений;
- у пользователя есть стабильный внутренний ID, который не зависит от имени, username или телефона;
- сообщение считается отправленным только после подтверждения сервера;
- локальное хранение клиента — кэш, а не единственная история переписки;
- доступность с VoiceOver и клавиатуры проверяется с первого дня;
- звонки Lenovo Messenger используются как донор проверенных идей, но старая архитектура не копируется целиком.

## Структура

- `web/` — доступный браузерный клиент;
- `worker/` — Cloudflare Worker и серверная логика;
- `shared/` — общие контракты и правила протокола;
- `docs/` — архитектурные решения и план.

## Первый запуск

```bash
npm install
npm run dev
```

Проверка API:

```text
/api/health
```

Продакшен Worker: `bulbam-api`.

## Старые проекты-доноры

- `MyMessenger` — Swift-клиент Lenovo Messenger, особенно полезен как лаборатория звонков, Opus, WebRTC, LiveKit и доступности;
- `LenovoMessengerCloudflareRelay` — старый relay-протокол и серверные идеи для звонков.

Они остаются отдельными проектами и не являются зависимостями Bulbam.
