# Статус «В сети» и последняя активность

Система активности отделена от WebSocket: соединение может оставаться открытым, когда приложение свернуто. Используется короткая аренда (50 секунд) для каждого активного сеанса устройства, подтверждаемая браузером примерно раз в 20 секунд только при видимой странице.

- `PUT /api/v1/presence/heartbeat` с `{"visible":true|false}` обновляет состояние только собственной авторизованной сессии.
- `GET /api/v1/presence` возвращает состояние **только участников существующих личных переписок**. Анонимные запросы получают HTTP 401.
- `GET|PUT /api/v1/presence/settings` дает пользователю право полностью скрыть свою активность от собеседников. Сервер никогда не возвращает скрытое время последнего посещения.
- Если Бульбам открыт на двух устройствах, закрытие одного не делает пользователя офлайн, пока второе устройство активно.
- Если браузер завершен, отключился интернет или ОС заморозила вкладку, статус онлайн автоматически истекает максимум примерно через 50 секунд. «В сети» не означает гарантии, что человек видит экран прямо в эту секунду.
- `lastSeenAt` соответствует последнему подтверждённому посещению приложения с видимой вкладкой. Старые данные сессий намеренно не подмешиваются: открытие приложения впервые после выпуска может отображаться как «Статус неизвестен».
- Интерфейс чата и карточки чата показывают статус на русском либо белорусском. Подпись чата включает статус для VoiceOver, но не прерывает чтение при периодических обновлениях.
- Статусы не публикуются в каталог поиска пользователей и не должны использоваться для массового отслеживания аккаунтов.

Примечание: модели приватности для групп и контактов необходимо разрабатывать отдельно. Установленная настройка изначально разрешает видимость активности только существующим личным собеседникам; любой пользователь может её выключить.
