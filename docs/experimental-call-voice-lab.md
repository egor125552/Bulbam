# Экспериментальная лаборатория звонков Бульбама

Статус: изолированная ветка experiment/call-voice-lab-20261026. Обычные звонки не обрабатываются, пока человек явно не включит эксперимент.

## Для пользователя

Во время аудиозвонка нажмите «Настройки звонка» и откройте отдельный диалог «Создать голос». Выберите обработку входящего голоса (слышите только вы) или своего исходящего голоса (слышит собеседник). Готовые режимы: без эффекта, тремоло, реверберация, рация с фильтрованным широкополосным белым шумом, радиопомехи. Параметры: частота и период тремоло, отражения, уровень и частота помех, положение влево/вправо и вверх/вниз, расстояние. Изменение применяется только после отдельной галочки «Включить голосовые эффекты». Пресеты сохраняются локально; эффект не включается автоматически при следующем звонке.

В режиме исходящего голоса кнопка «Запикать мой голос сейчас» кратко заменяет звук сигналом в отправляемой WebRTC-дорожке.

## Автоматическое запикивание, честные ограничения

Переключатель автоматического запикивания включается **только** если браузер подтвердил доступную локальную модель распознавания ru-RU через Web Speech API с processLocally=true. Облачное распознавание не включается. В большинстве мобильных браузеров локальная модель недоступна: переключатель отключён с объяснением причины. Когда доступна, распознаватель следит за промежуточными результатами и запускает сигнал на исходящей дорожке при обнаружении мата. Но слова могут быть произнесены **до** распознавания: точное беззадержечное запикивание пока НЕ реализовано. Для надёжного маскирования до передачи потребуется локальная потоковая ASR с временными метками и буферизированием звука.

## Безопасность обычных звонков

При выключении эффекта нет никакого Web Audio. Модуль не меняет SDP, TURN, сервер, E2EE, сообщения и звонки других пользователей. Для исходящего голоса используется replaceTrack с возвратом исходной дорожки при выключении. При смене режима микрофона граф останавливается и подключается снова на новом треке. При завершении звонка ресурсы звукового графа и распознавание останавливаются. Для входящего эффекта исходное HTML-воспроизведение отключается только после успешного подключения локального звукового графа. В случае ошибок интерфейс сообщает о проблеме вместо выдуманного успеха.

## Что проверить на настоящих устройствах до main

iPhone Safari + VoiceOver: открытие диалога, фокус, изменения пресета, закрытие. Два устройства: исходящий обработанный голос слышит собеседник, входящий эффект слышен только локально. Переключение mute/unmute, профиля микрофона, разговорный динамик, AirPods, наушники, стереопанорама, возвращение из фона, ICE/TURN восстановление, завершение и повторный звонок. Проверить громкость шипения и радио, чтобы обработка не маскировала речь.

При любой регрессии звонков оставить изменения в экспериментальной ветке. Автотесты и headless браузеры не заменяют настоящий iPhone и прослушивание.

Безопасность mute: при включении микрофонного mute отключается и обработанная WebRTC-дорожка целиком, включая генерируемое радиошипение и сигнал запикивания. При выключении mute она возобновляется вместе с микрофоном.
