# Поведение голосовых при включённой и выключенной защите

Это обязательное правило совместимости Бульбама.

Когда участники явно выключили защиту конкретного личного чата,
новые голосовые записываются, передаются и воспроизводятся
прежним способом, без шифрования. Плеер использует обычный
браузерный элемент audio: без дополнительных преобразований
каналов и без зависимости от ключей устройств.

Когда защита включена, новые сообщения и голосовые используют
защищённую передачу каждому доверенному устройству, если
ключи обеих сторон готовы. Если это пока невозможно, допускается
прежняя защищённая отправка уже проверенным общим ключом.
Никакого скрытого перехода в незашифрованный режим быть не должно.
Ошибки сети не считаются разрешением отправить данные открыто.

Для защищённых голосовых плеер центрирует сигнал при
воспроизведении, чтобы звук, ошибочно попавший только в левый
или правый канал, был слышен в обоих наушниках. Для обычных
незашифрованных голосовых эта обработка не применяется.

Переключение защиты не меняет файлы, отправленные ранее:
уже зашифрованные записи требуют прежних ключей.
Эти сценарии обязательно проверяются при следующих изменениях.
