# Живая проверка Бульбама для ИИ-агентов (`agent:live`)

Инструмент `scripts/agent-live.mjs` позволяет ИИ-агентам и разработчикам проверять Бульбам **вживую** на работающем сервере (локальном `http://localhost:3000` или staging/production через `BULBAM_SMOKE_SECRET`), без создания одноразовых тестов и без засорения реальной базы.

## Команды

### 1. Полная живая проверка одной командой
```bash
npm run agent:live -- verify
```
Что делает:
1. Проверяет готовность сервера (`GET /api/ready`).
2. Создаёт 3 реальных аккаунта (`smoke_agent_alice_*`, `smoke_agent_bob_*`, `smoke_agent_carol_*`).
3. Открывает личный чат и создаёт группу.
4. Проверяет вживую через HTTP API:
   - отправку сообщений и ответы (`replyToMessageId`),
   - переключение реакций между несколькими пользователями,
   - добавление, список и удаление из избранного,
   - пересылку сообщений между чатами с сохранением автора,
   - «Удалить у меня» (скрыто у отправителя, осталось у собеседника),
   - запрет (403) чужому пользователю удалять сообщение «У всех»,
   - «Удалить у всех» (исчезает у всех, а цитата ответа превращается в «Сообщение удалено»).
5. Автоматически удаляет за собой все `smoke_agent_*` аккаунты и их переписки.

Чтобы оставить песочницу для проверки в браузере (Playwright / VoiceOver), добавьте `--keep`:
```bash
npm run agent:live -- verify --keep
```

### 2. Создать живые тестовые чаты для браузера (Playwright / ручной проверки)
```bash
npm run agent:live -- seed
```
Возвращает JSON с `username`, `password`, `cookie`, `directChatId` и `groupChatId` для Алисы, Боба и Кати. Агент может сразу войти под Алисой в браузере и проверить UI, диалоги и VoiceOver-семантику на реальных данных.

### 3. Убрать все тестовые аккаунты песочницы
```bash
npm run agent:live -- cleanup
```
Удаляет только аккаунты с префиксом `smoke_agent_` (или `--prefix=smoke_...`), реальные аккаунты владельца и пользователей никогда не затрагиваются.

## Работа с удалённым сервером (staging / production)

```bash
BULBAM_BASE_URL=https://your-bulbam.workers.dev \
BULBAM_SMOKE_SECRET=your_secret \
npm run agent:live -- verify
```
На локальной машине секрет не нужен: скрипт использует локальную D1 SQLite базу Wrangler. На удалённом сервере используются только уже защищённые `SMOKE_SECRET` маршруты `/api/v1/smoke/invite` и `/api/v1/smoke/cleanup`.
