# AccessPilot. Автономное исследование доступности Бульбама

AccessPilot запускает **настоящие обработчики навигации** Бульбама в
изолированном виртуальном HTML-документе. Физическое окно не открывается.
Тестировщик сам находит кнопки разделов, пробует переходить по ним и
собирает сведения о названиях элементов, их состоянии и происхождении
в исходном коде.

Запуск из корня проекта после `npm install --legacy-peer-deps`:

```sh
npm run test:accessibility
```

Отчёты создаются в папке `accesspilot-report`:
`Отчёт доступности Бульбама.txt` и
`Отчёт доступности Бульбама.json`.
Папка не отправляется в GitHub.

## Что выполняется

- Проверяются главный экран, категории настроек и вложенные страницы.
- Переходы находятся автоматически: нет заранее записанного маршрута
  на каждую категорию.
- Для каждой кнопки и поля выводятся название, роль, состояние и, где
  возможно, место создания элемента и регистрации обработчика нажатия.
- Нажатия открывающих, закрывающих и возвращающих кнопок запускают
  настоящие функции интерфейса, результат записывается в отчёт.
- Находятся пустые доступные имена, неправильные ссылки
  `aria-labelledby`, положительный `tabindex` и некоторые ошибки
  нестандартных кнопок.
- Действия изменения аккаунта, отправки сообщений, звонков и удаления
  данных не выполняются. Для них создаётся только запись об элементе.

## Чего тест НЕ обещает

Это **виртуальная проверка DOM**, а не запись настоящего VoiceOver.
Фразы в поле `predictedAnnouncement` являются приближённым
представлением данных доступности; скринридер может говорить иначе.
Виртуальная среда не выполняет CSS-раскладку, сетевые операции,
реальные аудио- и телефонные функции, проверку фокуса настоящего
браузера или поток живой речи VoiceOver. Сюда не входят полные сценарии
авторизации и переписки. Неактивированные кнопки нельзя считать
функционально проверенными. Отсутствие найденных ошибок не означает,
что программа полностью доступна.

## Архитектура

`engine.js` — универсальный автономный обход с ограничениями числа
экранов, глубины и нажатий. Не знает о Бульбаме и его кнопках.

`dom.js` — анализ доступных названий и состояний элементов без
зависимости от конкретного приложения.

`bulbam-adapter.js` — отдельная тестовая среда Бульбама: загружает
реальный HTML, подключает существующие обработчики, подменяет только
недоступные в виртуальном DOM функции окна и помечает безопасные
переходы. Никакого подключения к серверу и токенов нет.

`run.js` — запуск и текстовые/JSON-отчёты.

Для поддержки других программ достаточно написать свой адаптер.
Каждая среда может предоставлять больше достоверных сведений,
например данные настоящего браузерного дерева доступности.
